===================================================
        CHECKLIST FOR SYSTEM TESTING (QA & UAT)
===================================================

[ ] 1. ระบบ Authentication & Login
  [ ] 1.1 Login Supervisor
    [ ] เข้าสู่ระบบด้วย Email/Password ที่ถูกต้อง
    [ ] เข้าสู่ระบบด้วย Email/Password ที่ผิด (แจ้งเตือนถูกต้อง)
    [ ] เข้าสู่ระบบครั้งแรก (บังคับตั้งค่า 2FA)
    [ ] สแกน QR Code สำหรับตั้งค่า 2FA (Google/Microsoft Authenticator)
    [ ] กรอก OTP 6 หลักถูกต้องเพื่อตั้งค่า 2FA
    [ ] กรอก OTP 6 หลักผิด (แจ้งเตือนรหัสผิด)
    [ ] ทดสอบการเข้าสู่ระบบครั้งถัดไป ต้องถามหา 2FA เสมอ
    [ ] ทดสอบการใช้ Recovery Keys แทน OTP ในกรณีฉุกเฉิน
  [ ] 1.2 Login Admin
    [ ] เข้าสู่ระบบด้วย Email/Password ที่ถูกต้อง
    [ ] เข้าสู่ระบบด้วย Email/Password ที่ผิด
    [ ] ทดสอบการรับและกรอกรหัส OTP (ผ่าน Email หรือ SMS) เพื่อเข้าสู่ระบบ
    [ ] กรอก OTP ผิด หรือ ปล่อยให้ OTP หมดอายุ
    [ ] บังคับตั้งรหัสผ่านใหม่ (New password) กรณีเข้าใช้งานครั้งแรก
    [ ] ตั้งรหัสผ่านใหม่สำเร็จและทดสอบล็อกอินด้วยรหัสใหม่

[ ] 2. ระบบจัดการข้อมูลพื้นฐาน (Supervisor & Admin)
  [ ] 2.1 จัดการความคิดเห็น (Comment)
    [ ] ดูรายการ Comment ทั้งหมด
    [ ] ค้นหา / กรอง / เรียงลำดับ Comment
    [ ] ลบ Comment ที่ไม่เหมาะสม
    [ ] ปิดบัง/ซ่อน Comment จากหน้าเว็บ
  [ ] 2.2 จัดการการติดต่อ (Contact)
    [ ] ดูรายการข้อความที่ส่งมาจากผู้ใช้งาน
    [ ] กดดูรายละเอียดข้อความ
    [ ] เปลี่ยนสถานะข้อความ (เช่น อ่านแล้ว, ยังไม่อ่าน, ดำเนินการแล้ว)
    [ ] ลบข้อความที่ติดต่อเข้ามา
  [ ] 2.3 จัดการกิจกรรม (Activities)
    [ ] เพิ่มกิจกรรมใหม่ (กรอกข้อมูลครบถ้วน และอัปโหลดรูปภาพสำเร็จ)
    [ ] ตรวจสอบดักจับข้อผิดพลาด (Validation เช่น ไม่กรอกชื่อ, อัปโหลดไฟล์ผิดประเภท)
    [ ] ดูรายการกิจกรรมทั้งหมด
    [ ] แก้ไขข้อมูลกิจกรรม และรูปภาพ
    [ ] ลบกิจกรรม
  [ ] 2.4 จัดการประชาสัมพันธ์ (Public Relations)
    [ ] เพิ่มข่าวประชาสัมพันธ์ใหม่
    [ ] แนบไฟล์รูปภาพ หรือเอกสารในข่าวประชาสัมพันธ์
    [ ] ดูรายการข่าวประชาสัมพันธ์ทั้งหมด
    [ ] แก้ไขข่าวประชาสัมพันธ์
    [ ] ลบข่าวประชาสัมพันธ์
  [ ] 2.5 จัดการ Slider หน้าหลัก
    [ ] เพิ่มภาพ Slider ใหม่ลงหน้าหลัก
    [ ] ตรวจสอบขนาด/ชนิดของไฟล์ภาพ Slider
    [ ] จัดเรียงลำดับการแสดงผลของ Slider (Reorder)
    [ ] ปิด/เปิด การแสดงผลของภาพแต่ละภาพ (Toggle Visibility)
    [ ] ลบภาพ Slider 

[ ] 3. ฟังก์ชันเฉพาะของ Supervisor (Part Supervisor)
  [ ] 3.1 การดูและจัดการคำร้อง (Requests)
    [ ] ดูรายการคำร้องทั้งหมดที่ส่งเข้ามา
    [ ] ดูรายละเอียดคำร้องเจาะจงแต่ละบุคคล
    [ ] กดอนุมัติ (Approve) คำร้อง
    [ ] กดปฏิเสธ (Reject) คำร้อง
    [ ] ค้นหาและกรองสถานะคำร้อง
  [ ] 3.2 จัดการสมาชิก Supervisor
    [ ] ดูรายชื่อ Supervisor ทั้งหมดในระบบ
    [ ] ระงับบัญชี (Suspend) -> และทดสอบนำบัญชีที่ถูกระงับไปล็อกอิน (ต้องเข้าไม่ได้)
    [ ] ปลดระงับบัญชี (Unsuspend)
    [ ] ลบบัญชี (Delete) ถาวร
    [ ] บังคับให้เปลี่ยนรหัสผ่าน (Force Reset Password) 

[ ] 4. ฟังก์ชันเฉพาะของ Admin (Part Admin)
  [ ] 4.1 จัดการสมาชิก Admin ด้วยกัน
    [ ] ดูรายชื่อ Admin ทั้งหมดในระบบ
    [ ] ค้นหา Admin จากชื่อ หรือ Email
    [ ] ระงับบัญชี (Suspend) -> ทดสอบล็อกอินด้วยบัญชีนั้น (ต้องเข้าไม่ได้)
    [ ] ปลดระงับบัญชี (Unsuspend)
    [ ] ลบบัญชี Admin (Delete)
    [ ] บังคับให้เปลี่ยนรหัสผ่าน (Force Reset Password)

[ ] 5. เรื่องที่ควรทดสอบเพิ่มเติม (General System Tests)
    [ ] ทดสอบ Responsive เปิดหน้าต่างย่อขยาย หรือเล่นในมือถือ UI ไม่พัง
    [ ] อัปโหลดไฟล์ที่มีขนาดใหญ่เกินกำหนด (ต้องโดนบล็อก)
    [ ] การเข้าถึงลิงก์ที่ไม่มีสิทธิ์ (เช่น Admin พิมพ์ URL เข้าหน้าของ Supervisor ต้องโดนเด้งออก)
